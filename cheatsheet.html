The 4-Bit Chunking Trick

Never do long division! To convert binary to hex (e.g. 11010110₂):

  1. Group into sets of 4 from the right: 1101 and 0110.
  2. Decode each 4-bit nibble: 1101 = 13 = D, 0110 = 6.
  3. Result: 0xD6 in 3 seconds flat!
2

Two's Complement Speed Trick

To negate an 8-bit number without subtracting:

  1. Method 1: Flip all bits (0 to 1, 1 to 0) and add 1.
  2. Method 2 (Fastest): Scan from right to left. Leave all bits unchanged up to and including the very first 1. Flip all bits to the left of it!
  3. Example: 0010 1100 → Right part: ... 100, Flip left: 1101 0100!
3

Even vs Odd Binary Rule

Look only at the Least Significant Bit (LSB / Bit 0):

  • If Bit 0 is 1, the number is ODD (since 2° = 1 and all other powers of 2 are even!).
  • If Bit 0 is 0, the number is EVEN.

Standard Prefixes & Notations

Recognize numbers in code and homework:

  • 0b1011 = Binary (Prefix 0b)
  • 0o755 = Octal (Prefix 0o)
  • 0xDEADBEEF = Hexadecimal (Prefix 0x)
  • 1011₂ or FFA₁₆ = Subscript base notation
